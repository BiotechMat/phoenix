# Decision register

One file per decision, numbered in order. Decisions are never edited after
the fact; a later decision supersedes an earlier one and says so. Use
[the template](TEMPLATE.md) for new entries. A new decision takes the next
free number in this file on `origin/main` at the moment it is committed.

A limit, a capital tranche, a venue, a promotion to live and an override of
a stop are always decisions (charter section 5).
