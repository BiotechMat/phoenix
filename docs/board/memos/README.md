# Board memos

One file per convening of the board, named `YYYY-MM-DD-<topic>.md`. A memo
records the question as asked, the seats convened, each position as given,
agreement and dissent, stops raised, unverified items by stage, needs
between seats, and the draft decision it proposed with the number it took
or a note that the CEO did not decide. Memos are the record for later
sessions; the decisions they propose live in `../decisions/`.
